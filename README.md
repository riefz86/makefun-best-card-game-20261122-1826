Ember Pact — duel kartu elemen di browser. Kamu dan Sang Rival sama-sama punya 30 HP, satu dek 24 kartu dari empat elemen (Bara, Ombak, Daun, Batu), dan mana yang tumbuh tiap giliran. Mainkan kartu, picu Resonansi +2 dengan dua kartu selemen dalam satu giliran, dan kalahkan rival sebelum HP-mu habis.

## Run it

```sh
node serve.ts
```

Lalu buka http://localhost:8080 — klik kartu untuk memainkannya, Spasi untuk mengakhiri giliran, M untuk suara.
